# PEA Tracker v1.1.1 — Financial confirmation navigation fix

23 November 2026. Patch release preserving the V1.1.0 financial foundation.

## Fixes

- Confirmation links opened from ChatGPT could include `?utm_source=chatgpt.com`.
  The route rejected every URL query before authentication with `origin_forbidden`.
- GET navigation now ignores only the known tracking keys `utm_source`,
  `utm_medium`, `utm_campaign`, `utm_term`, `utm_content` and `utm_id`. Other query
  keys remain rejected; approval POST requests still reject all URL queries and
  the form action contains no tracking parameters.
- The confirmation and approval-result pages use a responsive layout, readable
  mobile rows and an accessible approval button. Styles use a per-response CSP
  nonce; no framework, scripts, external assets or `unsafe-inline` were added.

## Security and compatibility

Cloudflare Access, owner identity, distinct audiences, CSRF, expiry, immutable
intent validation, single-use approval and idempotent journal behavior are
preserved. No financial calculations, REST/MCP contracts, secrets, Access/OAuth
configuration or D1 schema/data were changed. V2 developments are excluded.

## Validation and production deployment

- 29 distinct targeted financial MCP tests passed, including the official SDK
  and native local D1 journey with a tracked confirmation URL. The D1 case exceeded
  its original five-second deadline, then passed alone with a fifteen-second CLI
  deadline. TypeScript and diff checks passed. Existing evidence was reused during
  delivery; no test suite was rerun.
- Synthetic Chrome rendering was inspected at 1280px and 390px: no horizontal
  overflow, stacked mobile rows, 48px approval button and CSP-authorized styling.
- Deployed source: `98872bbc3682ca05f8e0d39d719ec310b5d5f4e4` on `main`.
- Worker: `pea-tracker-financial-read`, version
  `aef16740-0557-4d8d-a080-0bb182e33342`, replacing
  `84f0d820-dd10-4f81-9c60-6c83e48e591d`, using the approved private configuration
  with `--keep-vars`. No migration or financial operation was executed.
- Minimal post-deployment checks: anonymous MCP HTTP 401; confirmation navigation
  with UTM HTTP 302 to authentication. These prove the protected endpoint responds,
  not that the authenticated business journey has completed.

## Remaining acceptance

The owner will separately validate opening the link from ChatGPT, independent
browser approval, the first real MCP journal write, its unique receipt/replay and
resulting positions, cost basis and cash. This release does not claim that journey
is production-validated. No brokerage order is placed by PEA Tracker.
