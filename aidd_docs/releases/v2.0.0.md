## Scope

V2.0 integrates the A–E workstreams while preserving the V1.1.5 financial discovery
and independent approval model. It prepares multi-portfolio consultation and
separate real/simulated financial circuits without changing financial formulas
or placing brokerage orders.

- Owner-scoped registry with immutable opening anchors and deterministic adoption
  of the existing portfolio. Administrative creation remains an internal capability,
  not a public MCP tool or REST endpoint.
- Versioned read-only REST `/api/v2/portfolios` and MCP discovery, details, state and
  valuation. Registry discovery replaces the V1 singleton only when present; there
  is exactly one `list_portfolios` registration. Historical V1.1 contracts remain.
- Real operations retain independent browser approval, exact intent/digest, expiry
  and idempotent receipts. Simulated operations use a separate explicit confirmation
  circuit and cannot authorize real writes. Owner/kind/anchor/archive guards apply.
- Multi-provider mapping, normalization, provenance and source-time nonregression
  are available in isolated observation components. Yahoo remains primary.
- Configurable collector cadence supports 15 minutes while keeping the existing
  30-minute default. Session-reuse experiments remain outside the active collector.
