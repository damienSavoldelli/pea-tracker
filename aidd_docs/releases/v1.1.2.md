# PEA Tracker v1.1.2 — Financial confirmation interface

23 November 2026. Presentation-only patch, preserving V1.1 financial rules and
V1.1.1 tracking-safe confirmation navigation. No V2 developments are included.

## Changes

- Blue responsive identity, PEA Tracker header and static inline icon across
  confirmation, approval-success and error pages.
- Structured instrument/ticker/ISIN, Paris-local execution time, prominent quantity
  and calculated unit price, gross amount, declared fees and total debit/net credit.
  Cash and position impacts reuse the server preview. Missing values are not invented;
  unit-price display reuses exact fraction helpers and labels rounded results.
- Technical references are grouped in an expandable section.
- Absolute expiry time, MM:SS countdown refreshed every second and a progress bar.
  Warning colors begin at 60s and 30s; expiry disables the approval button and asks
  for a new proposal. Reloading does not reset the deadline. The server remains
  authoritative and the form is usable without JavaScript.
- Minimal native JavaScript and styles use CSP nonces. No external dependency,
  framework or `unsafe-inline`. Approval button has hover/focus/disabled states,
  10px vertical padding and a minimum height of 44px.
- Success explicitly distinguishes approval from journal recording. It shows a
  proposal reference, not an invented receipt. Expired/already-used/authentication
  and other existing errors retain their HTTP status and reveal no proposal details.

## Validation

- 33 targeted financial MCP tests passed, including CSP, absolute countdown,
  reload/expiry, Paris winter/summer time, missing fees, structured recap, error
  rendering, UTM/CSRF controls and the existing official-SDK/native-local-D1 journey.
- TypeScript and diff checks passed; no full application suite was run.
- Synthetic Chrome checks: confirmation at 1280px and 390px, status templates at
  390px; screenshots inspected, no horizontal overflow, correct blue 44px button
  and actual nonce-authorized countdown running.
