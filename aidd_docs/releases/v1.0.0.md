# PEA Tracker v1.0.0 — Portfolio reads and valuation

First functional release, accepted with minor reservations on 19 November 2026.

## Features

- Read REST and MCP APIs using the same business services; read-only MCP.
- Initial portfolio, positions, cash and valuation reads, with exact decimal calculations in the backend.
- Production coverage validated for 20 instruments, without publishing holdings or private amounts.
- Yahoo Finance quotations through Python/yfinance, with explicit provider, market/collection timestamps and freshness warnings.
- Cloudflare Cron scheduling and a Durable Object dispatch ledger; collector execution through GitHub Actions `workflow_dispatch`.
- Cloudflare Access, machine ingestion separate from reads, explicit authorization and batch idempotency. Cryptographic and temporal JWT validation retained; the arbitrary five-minute cap on total assertion lifetime removed.
- Old GitHub schedules and the diagnostic workflow removed. Closing monitoring prepared for 20:09 Paris time to check the last expected slots.

## Production validation — 19 November

21 consecutive automatic collections succeeded from 08:47 to 18:47, each delivering 20 observations with zero unavailable. The 13 expected monitoring runs from 07:09 to 19:09 executed; the 08:09 run correctly reported the absence of a successful cycle, then subsequent checks succeeded.

The morning incidents remain recorded: HTTP 401 at 07:17, 07:47 and 08:17; successful controlled validation at 08:15; stable automatic recovery from 08:47 onward. Targeted local checks cover JWTs, the Python–ingestion chain and slot normalization. The 19 November closure is neither a service guarantee nor a disaster-recovery exercise.

## Limitations and next steps for V1.1

- Quotations are not guaranteed to be real time; a market calendar and reliable freshness remain to be developed.
- Dated opening portfolio: no complete transaction journal or historical-performance engine.
- Yahoo/yfinance is a non-contractual source; availability and delays depend on external services.
- Current monitoring checks how recent successes are; its end-of-day check still needs production verification after deployment.
- Revocation of assertions verified offline is bounded by their expiry; no instant revocation is claimed.
- V1.1: calendar/freshness, transactions and cash movements, PRU, performance and monitoring. Financial rules remain to be decided under the PRD; calculations belong in the domain and are never delegated to ChatGPT.
- V2.0: multiple portfolios and providers; V2.1: OHLCV, watchlists and indicators; V2.2: Trading Lab journal; V2.3: analysis and interfaces. The real PEA remains the priority.

No secret, private amount, holdings list or financial journal is included in this release.
